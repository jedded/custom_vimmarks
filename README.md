# Vim Marks Sidebar

VSCodeVim 일반 모드에서 쓰는 **전역 마크(a-z, A-Z)** 와 **사이드바 목록**입니다.
단축키는 확장에 내장되어 있어서 `settings.json`을 수정할 필요가 없습니다.

- 모든 글자가 전역 마크입니다. 다른 파일로도 이동합니다.
- 사이드바(활동 표시줄의 `Marks` 아이콘)에 마크 목록이 계속 표시됩니다. 뷰 제목을 끌어서 오른쪽 보조 사이드바나 아래 패널로 옮길 수 있습니다.
- 목록 정렬은 **찍은 순서 / 글자순**을 키로 토글합니다.
- 마크한 줄 옆(거터)에 글자가 표시됩니다.
- 마크는 워크스페이스 단위로 저장되어 VS Code를 다시 열어도 유지됩니다.
- 줄을 추가/삭제하면 마크 줄 번호가 따라갑니다.

## 내장 단축키

조건: `vim.active && vim.mode == 'Normal'` (VSCodeVim 일반 모드)

| 키 | 동작 |
|---|---|
| `m` + 글자 | 현재 위치에 마크 (예: `m q`, 대문자는 `m shift+a`) |
| `'` + 글자 | 마크한 줄로 이동 (줄의 첫 글자) |
| `` ` `` + 글자 | 마크한 정확한 위치로 이동 |
| `, z` | 정렬 토글 (찍은 순서 ↔ 글자순) |
| `, v` | 마크 목록 뷰에 포커스 |

목록 항목을 클릭하면 이동하고, 항목의 휴지통 아이콘으로 삭제합니다. 뷰 제목의 아이콘으로 정렬 토글과 전체 삭제를 할 수 있습니다.

## 단축키 바꾸기

- 사용자 `keybindings.json`이 확장 내장 단축키보다 우선합니다. 같은 키를 쓰면 사용자 설정이 이깁니다.
- 내장 단축키를 끄려면 `keybindings.json`에 `-`를 붙인 항목을 넣으세요. 예: `{ "key": ", z", "command": "-vimMarks.toggleSort" }`
- 내장 단축키 목록은 `scripts/gen_keybindings.py`로 다시 생성합니다.

## 한계

- VSCodeVim의 기본 `m`, `'`, `` ` ``(일반 모드)를 가로챕니다. `d'a` 같은 연산자 뒤의 마크 이동은 지원하지 않습니다.
- 한 줄에 마크가 여러 개면 거터에는 하나만 보입니다. 목록에는 모두 나옵니다.
- 코드가 바뀌면 줄 번호만 보정하고 열 번호는 보정하지 않습니다.
