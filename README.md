# Vim Marks Sidebar

VSCodeVim 일반 모드에서 쓰는 **전역 마크(a-z, A-Z)** 를 **프로젝트 단위로 묶어서** 사이드바에 계속 보여 줍니다.
단축키는 확장에 내장되어 있어서 `settings.json`을 수정할 필요가 없습니다.

- 모든 글자가 전역 마크입니다. 다른 파일로도 이동합니다.
- 사이드바(활동 표시줄의 `Marks` 아이콘)에 **프로젝트 → 마크** 순서로 목록이 표시됩니다.
- **프로젝트를 클릭해 선택**하면, 그때부터 찍는 마크는 선택된 프로젝트에 계속 쌓입니다. 다른 일을 하다가 프로젝트를 바꿔도 이전 프로젝트의 마크는 그대로 남습니다.
- 마크는 **VS Code를 껐다 켜도 유지**됩니다. 폴더가 달라도(창이 달라도) 같은 프로젝트를 이어서 쓸 수 있습니다.
- 이미 쓰고 있는 글자로 다른 위치에 `m` + 글자를 누르면 **덮어쓸지 `y`/`n`으로 물어봅니다.** 한 글자만 누르면 바로 선택되고, `Enter`와 `Esc`는 안전하게 `n`(기존 마크 유지)입니다. 새 글자는 묻지 않습니다. **같은 줄에서 같은 글자로 다시 누르면 묻지 않고 그 마크를 삭제(토글)합니다.** 다시 누르면 다시 찍힙니다. 사이드바 제목의 방패 아이콘으로 이 확인을 끄고 켤 수 있고, 선택은 기억됩니다.
- **마우스로 끌어서 순서를 바꿀 수 있습니다.** 같은 섹션 안에서 마크를 다른 마크 위에 놓으면 그 자리로 옮겨지고, 섹션 제목이나 빈 곳에 놓으면 맨 뒤로 갑니다. 섹션 자체도 끌어서 순서를 바꿉니다. 끌면 순서 번호가 새로 매겨지므로 그 뒤로는 "찍은 순서"가 아니라 **사용자가 정한 순서**가 됩니다. 새로 찍는 마크는 맨 뒤에 붙습니다.
- 목록 보기는 두 가지이고 `, z`로 토글합니다.
  1. **찍은 순서**: 마크를 찍은 순서대로 한 줄씩 표시 (기본)
  2. **파일별**: 프로젝트 아래에 파일 단위로 묶고, 각 파일 안에서는 줄 번호 순으로 표시
- 마크한 줄 옆(거터)에 글자가 표시됩니다. (선택된 프로젝트의 마크만)
- 줄을 추가/삭제하면 **모든 프로젝트의** 마크 줄 번호가 따라갑니다.
- 뷰 제목을 끌어서 오른쪽 보조 사이드바나 아래 패널로 옮길 수 있습니다.

## 사이드바 사용법

| 동작 | 방법 |
|---|---|
| 프로젝트 선택 | 프로젝트 항목 클릭 (선택된 프로젝트는 ● 아이콘 + `active` 표시, 펼쳐져 있음) |
| 새 프로젝트 | 뷰 제목의 `+` 아이콘 (또는 `, p` → `New project...`) |
| 이름 바꾸기 / 삭제 | 프로젝트 항목의 연필 / 휴지통 아이콘 |
| 마크로 이동 | 마크 항목 클릭 |
| 마크 삭제 | 마크 항목의 휴지통 아이콘, 또는 같은 줄에서 `m` + 같은 글자 |
| 마크 순서 바꾸기 | 마크를 끌어서 같은 섹션의 다른 마크 위에 놓기 (찍은 순서 보기에서만. 파일별 보기는 순서가 고정) |
| 섹션 순서 바꾸기 | 섹션 항목을 끌어서 다른 섹션 위에 놓기 |
| 보기 전환 (찍은 순서 ↔ 파일별) | 뷰 제목의 정렬 아이콘 또는 `, z` |
| 현재 프로젝트의 마크 전체 삭제 | 뷰 제목의 `clear-all` 아이콘 |
| 덮어쓰기 확인 끄기/켜기 | 뷰 제목의 방패 아이콘 (켜져 있으면 방패, 꺼져 있으면 금지 아이콘). 상태는 뷰 설명에 `overwrite: ask / no ask`로 표시 |

하단 상태 표시줄에 현재 프로젝트 이름이 표시되고, 클릭하면 프로젝트를 바꿀 수 있습니다.

## 내장 단축키

조건: `vim.active && vim.mode == 'Normal'` (VSCodeVim 일반 모드)

| 키 | 동작 |
|---|---|
| `m` + 글자 | 선택된 프로젝트에 마크 (예: `m q`, 대문자는 `m shift+a`). 같은 줄에서 같은 글자로 다시 누르면 삭제, 다른 줄이면 덮어쓸지 `y/n` 확인 |
| `'` + 글자 | 선택된 프로젝트의 마크 줄로 이동 (줄의 첫 글자) |
| `` ` `` + 글자 | 마크한 정확한 위치로 이동 |
| `, z` | 보기 전환 (찍은 순서 ↔ 파일별) |
| `, v` | 마크 목록 뷰에 포커스 |
| `, p` | 프로젝트 전환 (목록에서 선택 또는 새로 만들기) |

## 저장 위치

마크는 확장 전용 저장 폴더(VS Code의 `globalStorage`)에 `marks.json` 파일로 저장됩니다.
변경 후 약 0.2초 뒤와 종료 시에 저장합니다. 파일이 깨져 있으면 사본(`marks.corrupt-*.json`)을 남기고 빈 상태로 시작합니다.
WSL/SSH로 접속한 창에서는 접속한 쪽(서버)의 저장 폴더에 저장됩니다.

## 단축키 바꾸기

- 사용자 `keybindings.json`이 확장 내장 단축키보다 우선합니다.
- 내장 단축키를 끄려면 `-`를 붙인 항목을 넣으세요. 예: `{ "key": ", z", "command": "-vimMarks.toggleSort" }`
- 내장 단축키 목록은 `scripts/gen_keybindings.py`로 다시 생성합니다.

## 한계

- VSCodeVim의 기본 `m`, `'`, `` ` ``(일반 모드)를 가로챕니다. `d'a` 같은 연산자 뒤의 마크 이동은 지원하지 않습니다.
- 한 줄에 마크가 여러 개면 거터에는 하나만 보입니다. 목록에는 모두 나옵니다.
- 코드가 바뀌면 줄 번호만 보정하고 열 번호는 보정하지 않습니다. 확장이 꺼져 있던 동안 파일이 바뀌면, 마크한 줄의 텍스트를 기준으로 가까운 같은 줄을 찾아 이동합니다.
- 여러 창을 동시에 쓰면 마지막으로 저장한 창의 내용이 이깁니다. 창이 포커스를 받을 때 다른 창의 변경을 다시 읽습니다.
- 0.2.0까지 워크스페이스별로 저장하던 마크는 첫 실행 때 한 번 복사됩니다. `default` 프로젝트가 비어 있으면 거기로, 이미 마크가 있으면 **작업 폴더 이름의 새 프로젝트**로 복사해서 같은 글자의 기존 마크와 섞이지 않습니다. 옛 데이터는 지우지 않고 남겨 둡니다.
